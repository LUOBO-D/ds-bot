# 多角色卡

一个 QQ 号里可以装多张角色卡，随时切换。角色卡是纯文本，改完下一句就生效，不用重启。

## 怎么切

在 QQ 里直接对「阿鱼」说：

| 你说 | 效果 |
| --- | --- |
| `角色列表` | 列出所有卡，标出当前是哪张 |
| `切换角色 小鲸鱼` | 换成小鲸鱼（也可以说 `切到 小鲸鱼` / `换成 小鲸鱼` / `扮演 小鲸鱼`） |
| `当前角色` | 回你一句「现在是 xxx」 |
| `切回` | 回到默认卡（沈知微） |

接口层等价操作：

```http
GET  /api/personas              # {"active": "...", "items": [...]}
POST /api/personas {"persona": "小鲸鱼"}
```

## 文件在哪

```
assets/personas/
├── active.json        # 当前生效：{"active": "shenzhiwei"}
├── shenzhiwei.md      # 沈知微（27 岁文学编辑，女友向）
└── xiaojingyu.md      # 小鲸鱼（DeepSeek 小鲸鱼，软糯短句）
```

- `active.json` 里写 `slug`；没有这个文件时按 `.env` 的 `PERSONA_DEFAULT`（默认 `xiaojingyu`），再不行取第一张卡。
- 角色正文 = 整份 Markdown，会被原样塞进 system prompt 的 persona 段。
- 每次请求都重新读卡，所以改完立刻生效；桥接不用重启。

## 隔离规则

| 东西 | 是否按角色隔离 | 说明 |
| --- | --- | --- |
| 人设正文 | 是 | 各自的 `.md` |
| 长期记忆 `memories` | 是 | 表里有 `persona` 列，读写都带 slug |
| 情节记忆 `events` | 是 | 同上 |
| 生活线 `life_log` / `day_summary` | 是 | 同上 |
| 情绪 `mood:<slug>` | 是 | KV 里按角色分开存；切卡时 `Mood.reload()` |
| QQ 消息历史 `messages` | 否 | 同一个号，聊天记录共享（她能看到聊天记录里对方说过的话） |

老数据在迁移时统一归到 `persona='shenzhiwei'`。

## 写一张新卡

1. 在 `assets/personas/` 新建 `<slug>.md`（slug 用小写英文，例如 `xiaoyu`）。
2. 第一行写 `# 名字`（或者 `# 角色卡：名字`），这个名字会出现在 `角色列表` 里。
3. 建议分节：`你是谁` → `说话方式` → `和主人的关系` → `语气样例` → `底线`。
4. 规则尽量写成一行一条的短句，比长段落更稳。
5. 切过去：QQ 里说 `切换角色 名字`。
